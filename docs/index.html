kiko

基于 signal-polyfill 的细粒度响应式 DOM 库。JSX 直接编译为真实 DOM，无需虚拟 DOM，组件函数只执行一次。

核心特性

真实 DOM

JSX 工厂直接创建 HTMLElement 与 Text 节点，没有虚拟 DOM 和 diff 开销。

标准信号

基于 signal-polyfill（TC39 Signals 提案），返回标准 Signal.State / Signal.Computed。

细粒度更新

每个 signal 绑定独立 watcher，变化时只更新对应的文本、属性或子树。

scoped 样式

<style> 默认 Vue 风格 scoped：构造式样式表 + 选择器改写，无需模板 编译器。

控制流组件

Show、For、ErrorBoundary 与 Suspend，条件渲染、列表渲染、错误边界与异步挂起均基于 signal 与真实 DOM。

无构建可用

dom 标签模板在运行时翻译 JSX 语法，纯浏览器环境直接使用；React 组件也能 通过 ReactPortal 嵌入。
