概览

JSX 直接编译为真实 DOM 节点——没有虚拟 DOM，没有 reconciliation。 组件函数只执行一次，signal 绑定细粒度驱动 DOM 更新。

@kikojs/dom 不依赖 @kikojs/signal，它重新实现了自己需要的最小 signal 封装，保持 DOM 包自包含。如需应用层状态管理，可同时使用 @kikojs/signal（二者可直接互操作）。

安装与配置

bun add @kikojs/dom

在 tsconfig.json 中设置 JSX 导入源（或使用 @jsxImportSource 注释）：

JSX 工厂

jsx / jsxs / jsxDEV

导出 签名 说明
jsx jsx(tag: string | Component, props: Props | null): Node JSX 工厂，创建真实 DOM 节点。
jsxs jsxs = jsx 多子节点 JSX 工厂（React 兼容）。
jsxDEV jsxDEV = jsx 开发环境 JSX 工厂。

没有 JSX 编译器时可以直接调用工厂（htm 标签模板走的也是这条路）：

Fragment

签名 说明
Fragment(props): DocumentFragment 无包裹节点的多根内容容器。

Props 处理规则

prop 行为
children 为 string | number 创建 Text 节点。
children 为 Signal 创建 Text 并订阅细粒度更新。
children 为 Node 直接追加。
children 为 Array 递归处理。
children 为 Signal<Node | Node[]> 基于 marker 的结构性子树替换（Show / For 的底层机制）。
任意 prop 值为 Signal 创建 watcher，值变化时细粒度更新该属性（class、style、onXxx、data-* 等）。
onXxx 调用 addEventListener；值为 signal 时变化自动替换监听器（不泄漏）。
className 映射到 class 属性。
style 为 string | object 字符串直接设置；对象逐个设置 CSS 属性。
布尔属性（disabled、checked 等） 按存在性渲染，false / null 时移除。
ref 回调接收元素；返回函数则注册为卸载清理回调（见 ref 清理）。

渲染

render

签名 说明
render(root: Node, container: Element): () => void 将 JSX 树挂载到 DOM 容器，返回 dispose() 用于卸载并清理所有 watcher 和事件监听。

ref 清理

ref 回调接收 DOM 元素。如果回调返回一个函数，该函数会被注册为清理回调： 当 DOM 子树被卸载（如 Show / structural swap / dispose）时自动 调用。

createPortal

把节点渲染到任意容器（如 document.body），原位置只留锚点注释。 Modal / Tooltip / Dropdown 需要脱离文档流时使用；锚点随宿主树一起 dispose，移入容器的节点会被移除并清理 watcher。信号子节点先经 jsx 创建再整体移入，响应式更新与清理机制不变。

控制流

条件与列表通过组件表达，内部基于信号 + marker 做真实 DOM 的最小操作。

Show — 条件渲染

Props 类型 说明
when T | null | undefined | false（支持 signal） 条件值。
children Node | ((value: T) => Node) 条件为真时渲染的内容。
fallback Node 条件为假时渲染的内容（可选）。

when 为信号时才订阅更新：when={count.get() > 0} 求值后是纯 boolean，快照后不再响应；需 computed(() => count.get() > 0) 或直接 when={count} / when={visibleSignal}。子节点中的 {count} 另行通过 JSX 绑定响应。

For — 列表渲染

Props 类型 说明
each readonly T[] | Signal<readonly T[]> 列表数据。
children (item: T, index: () => number) => unknown 渲染函数，index 为访问器。
getKey (item: T, index: number) => unknown 可选。提供后进入 keyed 模式：按 key 复用 DOM 节点，children 的 item 变为访问器 () => T，原位更新不重跑渲染函数。

ErrorBoundary — 错误边界

Props 类型 说明
children () => unknown 延迟求值的渲染函数，其同步错误（初始渲染与 signal 驱动的重渲染）会被捕获。
fallback unknown | ((error: unknown) => unknown) 出错时渲染的内容；函数形式接收捕获的错误。
onError (error: unknown) => void 错误回调（可选）。
resetSignal / errorSignal Signal.State<unknown> 由调用方持有的重试 / 错误信号（可选）。

只捕获渲染路径中的同步错误；事件处理器等异步回调中的错误通过宿主 reportError 上报，不会被捕获。

Suspend — 异步挂起 / lazy — 代码分割

Props 类型 说明
children Promise<Node> | (Promise<Node> | Node)[] | Node | 信号 异步加载的内容；信号值变化时重新挂起。
fallback Node 等待时渲染的占位内容。

当 children 为 Promise（或包含 Promise 的数组）时，先渲染 fallback，全部 resolve 后切换到实际内容；多个 Promise 通过 Promise.all 等待，任一 reject 时通过 reportError 上报并保持 fallback。

children 也可以是信号（值可为 Promise / 数组 / 普通 节点）：信号变化时重新挂起，迟到的旧结果会被丢弃并清理其 watcher——适合由路由参数、 用户输入驱动的异步组件。

lazy(loader): AsyncComponent 提供代码分割：首次调用加载模块（并发调用 共享同一次加载，之后走缓存；加载失败清除缓存可重试）。异步组件（含 lazy 返回值）可作为 JSX 元素直接放进 Suspend——jsx 对异步组件返回 Promise<Node>，由 Suspend 处理：

Promise 出现在 Suspend 之外会抛出 "Promise rendered outside <Suspend>"——异步内容只能挂在 Suspend 下，错位放置会在运行时立即报错而非静默渲染。

Style — scoped css

<style> 默认启用 scoped 模式（Vue 风格）：选择器被改写并限定到 最近祖先元素（包含该 style 的元素），该元素会获得唯一的 data-kiko-vN 作用域属性。无需模板编译器——作用域通过后代组合器匹配， Show / For 动态插入的节点自动覆盖。添加 global 属性则不改写选择器， 直接全局注入。

Props 类型 说明
children string | Signal | Array CSS 文本（支持 signal 响应式更新）。
global boolean 全局模式：跳过选择器改写与作用域。
nonce string CSP nonce（降级为 <style> 元素时使用）。

选择器改写规则：

  • .card → [data-kiko-v1] .card, [data-kiko-v1].card（作用域根元素及其子孙）。
  • & .title → [data-kiko-v1] .title（& 即作用域根元素）。
  • :deep(.x) / :global(.x) → 穿透，保持无作用域。
  • @media / @supports / @layer / @container → 递归改写内部规则。
  • @keyframes / @font-face / @import → 原样透传。

实现基于构造式样式表：new CSSStyleSheet() + document.adoptedStyleSheets（Chrome 73+ / Firefox 101+ / Safari 16.4+）；不支持时自动降级为携带改写后文本的真实 <style> 元素。卸载时（dispose / Show 切换）自动从 adoptedStyleSheets 移除；子树重新挂载时 sheet 会被重新 adopt。

SSR — 服务端渲染

kiko 没有 vdom，组件函数是唯一事实来源——SSR 不做第二套渲染管线：服务端入口 注册字符串运行时，让 jsx / 控制流组件改产 HTML，同一套组件代码 双端复用。两种输出形式：

导出 说明
renderToFragment(() => …): Promise<string> 片段 HTML：任意子树，不带 doctype。
renderToDocument(() => …): Promise<string> 完整文档：根为 <html>，自动前置 <!DOCTYPE html>。

两个入口从 @kikojs/dom/server 导入（SSR 侧）；默认入口 @kikojs/dom 不含任何 SSR 代码——客户端 bundle 只带一个约 30 字节的 运行时桥，字符串渲染器可被 tree-shake 完全剔除；服务端 bundle 同理不含客户端 渲染路径。组件代码两端都从 @kikojs/dom 导入 jsx / 控制流组件，类型世界保持单一。

必须传函数（惰性求值）——JSX 会在 SSR 模式开启前被急切求值， 传值形态会在客户端模式下构建 DOM。

  • 信号：取当前快照（SSR 无响应式）；props 与 children 中的信号 均支持。
  • 异步：Suspend 等待 promise 后再输出（完整渲染）， lazy 模块自然可用；reject 时报 reportError 并渲染 fallback。
  • scoped Style：scope 属性挂在最近祖先元素上，选择器改写后输出 ——与客户端语义一致。
  • 事件处理器被丢弃（无法序列化）；ref / key 忽略。
  • 客户端专属：render / Router / ReactPortal 在 SSR 模式下不可用。
  • 并发安全：SSR 运行时在服务端 bundle 中永久生效、无开关翻转， 多个并发渲染天然互不干扰。

hydrate — 客户端水合

hydrate(root, container): () => void 采纳 SSR 产出的现有 DOM： 组件树按 SSR 输出的注释标记（<!---->、 <!--show--> 等）逐节点对齐，挂上事件监听与信号绑定， 不重建 DOM。假设客户端初始状态与 SSR 一致（信号快照、分支选择、列表内容）。 返回 dispose() 用于卸载与清理。

  • 信号 / Show / For：采纳现有内容后照常挂 watcher，后续更新 走 marker 交换，与客户端渲染一致。
  • Suspend / lazy：模块内容在客户端构建后整体换入，内部绑定随之 生效；未加载完前保留 SSR 内容（无闪烁）。
  • Style：保留 SSR 输出的 <style> 元素与 祖先上的 scope 属性，不做 constructable sheet 优化。
  • 错位容忍：标签不匹配 / 节点不足时告警并尽力对齐， 不中断水合。

结合 htm — 无构建 JSX

kiko 不内置 htm 适配器。htm 是一个零依赖的标签模板运行时，在不支持 JSX 的环境（纯浏览器、无构建脚本、REPL）中，把 类似 JSX 的模板字符串翻译成 h(tag, props, ...children) 调用——与 JSX 编译产物的形式一致。自行安装 htm 并写约 10 行胶水代码接到 kiko 的 jsx 工厂即可，之后的一切（组件、信号、 <style> 作用域、Show / For）都是 kiko 已有的能力： 

bun add htm
  • 插值位置：文本、属性值、引号内属性值（字符串化）、标签（<${Component}>）、 ...${props} 展开。
  • 空白规则与 JSX 一致：换行锚定的纯空白文本节点被剔除。
  • 多根模板返回 DocumentFragment。
  • 限制：<!DOCTYPE> 会被当作标签（htm 限制）；动态标签名必须是完整插值（<${Tag}>）。

ReactPortal

签名 说明
ReactPortal(props: { component: React.ComponentType, ...rest }): HTMLElement 将 React 组件嵌入 kiko 树。Signal prop 变化自动触发 React 重渲染。
react 与 react-dom 是 peer dependency，仅在使用 ReactPortal 时由项目提供。从 @kikojs/dom/react-portal 子路径导入。

Signal 封装

@kikojs/dom 重新实现了最小 signal 子集（自包含，不依赖 @kikojs/signal）：

导出 说明
createSignal<T>(initial): Signal.State<T> 自包含的信号创建。
isSignal(value): value is WatchableSignal Signal 类型守卫。
createWatcher(cb): Watcher 创建标准 watcher。

对于完整的 signal 工具集（computed, effect, batch, on, emitter 等），请使用 @kikojs/signal。
