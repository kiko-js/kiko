@kikojs/dom

JSX 直接编译为真实 DOM 节点——没有虚拟 DOM，没有 reconciliation。 组件函数只执行一次，signal 绑定细粒度驱动 DOM 更新。

@kikojs/dom 不依赖 @kikojs/signal，它重新实现了自己需要的最小 signal 封装， 保持 DOM 包自包含。如需应用层状态管理，可同时使用 @kikojs/signal。

安装与配置

bun add @kikojs/dom

在 tsconfig.json 中设置 JSX 导入源：

JSX 工厂

导出签名说明
jsx jsx(tag: string | Component, props: Props | null): Node JSX 工厂，创建真实 DOM 节点。
jsxs jsxs = jsx 多子节点 JSX 工厂（React 兼容）。
jsxDEV jsxDEV = jsx 开发环境 JSX 工厂。
Fragment Fragment(props): DocumentFragment 无包裹节点容器。

Props 处理规则

  • children 为 string | number → 创建 Text 节点。
  • children 为 Signal → 创建 Text 并订阅细粒度更新。
  • children 为 Node → 直接追加。
  • children 为 Array → 递归处理。
  • children 为 Signal<Node | Node[]> → 基于 marker 的结构性子树替换。
  • onXxx → 调用 addEventListener。
  • className → 映射到 class 属性。
  • style: object → 逐个设置 CSS 属性。
  • class / class: Signal → 支持 signal 驱动的 class 绑定（静态 class 与 signal class 合并）。

ref 清理

ref 回调接收 DOM 元素。如果回调返回一个函数，该函数会被注册为清理回调： 当 DOM 子树被卸载（如 Show / structural swap / dispose）时自动调用。 

<div ref={el => {
  const observer = new ResizeObserver(entries => console.log(entries))
  observer.observe(el)
  return () => observer.disconnect() // 卸载时自动清理
}} />

render

签名说明
render(root: Node, container: Element): () => void 将 JSX 树挂载到 DOM 容器，返回 dispose() 用于卸载并清理所有 watcher 和事件监听。

Show

Props类型说明
whenT | null | undefined | false条件值（支持 signal）。
childrenNode | ((value: T) => Node)条件为真时渲染的内容。
fallbackNode条件为假时渲染的内容（可选）。

For

Props类型说明
eachT[] | Signal<T[]>列表数据。
children(item: T, index: () => number) => Node渲染函数，index 为访问器。

非 keyed 协调：列表变化时对比新旧并做最小 DOM 操作（复用、插入、删除）。

ErrorBoundary

Props类型说明
fallback(error: unknown) => Node出错时渲染的 fallback。
childrenNode受保护的子树。

Suspend

Props类型说明
fallbackNode等待时渲染的占位内容。
childrenPromise<Node> | Promise<Node>[]异步加载的内容。

当 children 为 Promise 或 Promise 数组时，先渲染 fallback， 所有 Promise resolve 后切换到实际内容。多个 Promise 通过 Promise.all 等待。

与 React 不同，kiko 组件函数只执行一次，因此 Suspend 适合一次性初始化。 如需在 signal 变化后重新加载数据，请使用 effect 或 Show 等响应式原语。

ReactPortal

签名说明
ReactPortal(props: { component: React.ComponentType, ...rest }): HTMLElement 将 React 组件嵌入 kiko 树。Signal prop 变化自动触发 React 重渲染。
react 与 react-dom 是 peer dependency，仅在使用 ReactPortal 时由项目提供。 从 @kikojs/dom/react-portal 子路径导入。

Signal 封装

@kikojs/dom 重新实现了最小 signal 子集：

导出说明
createSignal<T>(initial): Signal.State<T>自包含的信号创建。
isSignal(value): value is WatchableSignalSignal 类型守卫。
createWatcher(cb): Watcher创建标准 watcher。

对于完整的 signal 工具集（computed, effect, batch, on, emitter 等），请使用 @kikojs/signal。
