@kikojs/router

基于 signal 的声明式路由库。支持 path / hash 模式、嵌套路由、路由守卫、 查询参数解析、编程式导航，完全与 @kikojs/dom 和 @kikojs/signal 集成。

安装与导入

bun add @kikojs/router
import {
  createRouter,
  Router, Route, Link, Outlet, Navigate,
  useRouter, useParams, useQuery, useLocation, useRoute,
  createAuthGuard, combineGuards, createAsyncGuard,
  redirect, redirectReplace, buildPath, getQueryValue, pathsEqual, useNavigate,
  createPathHistory, createHashHistory,
} from "@kikojs/router"

createRouter

签名说明
createRouter(options: RouterOptions): Router 创建路由器实例，管理路由状态、导航与守卫。

RouterOptions

字段类型默认值说明
mode"path" | "hash""path"路由模式。
basestring""基本路径前缀。
guardsRouteGuard[][]全局路由守卫列表。
historyHistoryAdapter—自定义 history（覆盖 mode）。

组件

Router

Props类型说明
routerRouter路由器实例。
childrenNode子组件（通常包含 Link、Route、Outlet）。

Route

Props类型说明
pathstring匹配路径模式，支持 :param 动态段。
componentComponent匹配时渲染的组件。
guardsRouteGuard[]路由级守卫（可选）。
redirectstring匹配时重定向（可选）。

Link

Props类型说明
tostring目标路径。
replaceboolean替换当前历史记录（默认 false）。
stateunknown附加导航状态。
activeClassstring当前路径匹配时添加的 class。
childrenNode链接内容。

Outlet

Props类型说明
routerRouter指定路由器（可选，默认使用最近的 Router）。

渲染当前匹配 Route 的组件。用于嵌套路由布局。

Navigate

Props类型说明
tostring跳转目标。
replaceboolean替换当前历史记录。

渲染时立即执行导航，不渲染任何 DOM。

Hooks

Hook返回类型说明
useRouter()Router获取当前 router 实例。
useParams()RouteParams获取动态路由参数 signal。
useQuery()RouteQuery获取查询参数 signal。
useLocation()RouteLocation获取当前 location signal。
useRoute(){ route, matched, params, query, location }获取完整路由上下文 signals。
tryUseRouter()Router | null安全获取 router，Router 外返回 null。

路由守卫

导出签名说明
createAuthGuard createAuthGuard(predicate, redirectTo): RouteGuard 认证守卫：predicate 返回 falsy 时重定向。
combineGuards combineGuards(...guards: RouteGuard[]): RouteGuard 组合多个守卫，按顺序执行。
createAsyncGuard createAsyncGuard(check, redirectTo): RouteGuard 异步权限校验守卫。

守卫可以是同步或异步函数，返回 true（放行）、false（阻止）、 string（重定向路径）或 RedirectDescriptor。

History

导出说明
createPathHistory()创建基于 History API 的 path 模式 adapter。
createHashHistory()创建基于 hashchange 的 hash 模式 adapter。

通常不需要直接调用，createRouter({ mode }) 会自动选择。传入自定义 adapter 可用于测试或非浏览器环境。

工具函数

导出签名说明
redirectredirect(path, state?): RedirectDescriptor创建重定向描述（push）。
redirectReplaceredirectReplace(path, state?): RedirectDescriptor创建重定向描述（replace）。
buildPathbuildPath(path, query?): string构建带查询字符串的路径。
getQueryValuegetQueryValue(query, key): string | undefined从 query 对象提取单值。
pathsEqualpathsEqual(a, b): boolean比较路径是否匹配（忽略查询串和尾部斜杠）。
useNavigateuseNavigate(router): (to, options?) => void创建绑定 router 的导航函数。
