示例

从最小计数器到控制流与 React 桥接，快速了解 kiko 的使用方式。

计数器

组件函数只执行一次，只有 count 文本节点会随 signal 更新。

Suspend 异步挂起

在 Promise 或异步组件 resolve 之前显示 fallback。

kiko 组件函数只执行一次，因此 Suspend 仅适合一次性初始化。不要把 signal 作为 async 组件的依赖来驱动重新加载；需要响应式刷新时请使用 effect 配合 signal。

For 列表渲染
